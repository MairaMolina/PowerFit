# Power Fit Web

**Proyecto académico para el seguimiento de salud física, rutinas personalizadas y comunidad interactiva.**

## Propósito

Brindar a los usuarios una herramienta web para mejorar su bienestar físico mediante planes personalizados, seguimiento de progreso y contenido educativo.

## Estructura del proyecto

- `public/`: Archivos estáticos (HTML, imágenes, íconos)
- `src/`: Código fuente
  - `componentes/`: Elementos reutilizables
  - `paginas/`: Vistas como registro, perfil, rutinas
  - `utilidades/`: Funciones auxiliares
  - `estilos.css`: Estilos generales
  - `aplicacion.js`: Punto de entrada

## Funcionalidades clave

- Registro y autenticación
- Configuración de perfil
- Generación de planes personalizados
- Calculadora de IMC
- Comunidad Power Fit
- Exportación de planes en PDF

## Tecnologías

- HTML5, CSS3, JavaScript
- Axios (para conexión con backend)
- Live Server (para desarrollo local)
